# Security policy

This is a development tool. Use the latest coordinated Viewer/SDK release; older releases may lack authentication and LAN restrictions. Only the current release line receives fixes; no LTS commitment is made.

Please report suspected vulnerabilities privately via [GitHub private vulnerability reporting](https://github.com/DevMobileAn27/rn_network_viewer/security/advisories/new) when enabled. If that form is unavailable, open an issue requesting a private contact without vulnerability details, tokens or captured user data. Do not post exploits or sensitive captures publicly while arranging disclosure.

Include affected versions, platform, a minimal reproduction with synthetic data and expected impact. The maintainer will investigate and coordinate a fix/disclosure; there is no guaranteed response SLA or independent security audit.

See [the security model and limitations](docs/security.md).
